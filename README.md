How to run file:

1. Go to the folder where you wish to download Fast Notes and run this command: "git clone git@github.com:KjetilAlfredsen/IKT205_Assignment_1_Kotlin.git"
2. Open Android Studio, click "Open" and select the Folder (IKT204_Assignment_1_Kotlin).
3. Wait for Android Studio to complete the Gradle Sync.
4. Select an emulator and click the "Run" button.
